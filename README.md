# Hangman CLI

A simple command-line Hangman game written in Python that loads words from a text file.

## Requirements

* Python 3.x

## How to Run

1. Clone the repository:
   ```Bash
   git clone <repository-url>
   cd <repository-folder>
   ```
2. Run the script:
```Bash
   python main.py
```

3. When prompted for a file path, enter words.txt (or the path to your own text file containing space-separated words).

4. Enter an index number (1 or higher) to choose a secret word.
